## Two defects found while validating

Neither came from the merge itself; both were in code the merge brought forward.

1. **MSYS2 package name.** `prepare.py` requested
   `mingw-w64-x86_64-diffutils`, which no MSYS2 repository ships — diffutils
   exists only as `diffutils` in the `msys` repository. A cached `ThirdParty`
   entry normally hides this, so the stage only fails when its cache is gone.
   GitHub Actions drops caches not accessed for 7 days, which is what happened
   here (previous success 2026-09-19), and the build died in `Libraries` with
   `error: target not found`. Fixed to `diffutils`.

2. **Revoked Mapbox tokens.** 64Gram's `a5abb0d3a8` (2024-08) had commented out
   upstream's app-config lookup in `bot_attach_web_view.cpp` and
   `settings/business/settings_location.cpp` and hardcoded two `pk.` tokens.
   They are John Preston's, and Mapbox has revoked them (all four return
   HTTP 401), so the hardcoding had also been breaking the map feature.
   Both files now use upstream's `appConfig.get<...>(u"tdesktop_config_map")`
   lookup and are byte-identical to the upstream versions.
